# 🌐 Portfolio de Ruiz Juan Gabriel

Este es mi **portfolio personal**, desarrollado con **HTML, CSS y JavaScript**, diseñado para mostrar mis **habilidades en desarrollo web, UX, bases de datos y despliegue en la nube**.
El sitio está hecho con **diseño responsive** (*mobile first*) y estructura moderna para destacar mis proyectos y formación.

---

## 🚀 Tecnologías utilizadas

* **HTML5** – Estructura del sitio
* **CSS3** – Estilos, Flexbox, Grid y media queries para responsive design
* **JavaScript** – Interactividad y validaciones
* **Ionicons** – Iconos vectoriales
* **Fuentes Google Fonts** – Tipografía Oswald
* Diseño **mobile first** y **adaptable a distintos tamaños de pantalla**

---

## 📂 Secciones del Portfolio

* **Menú lateral** → Navegación rápida por el sitio
* **Título y presentación** → Información personal, perfil profesional y redes
* **Datos personales** → Contacto, edad, ubicación
* **Sobre mí** → Breve descripción, formación y competencias
* **Skills** → Tecnologías y herramientas que manejo
* **Formación académica** → Cursos y estudios realizados
* **Proyectos** → Mis trabajos con enlaces a demos
* **Footer** → Información de autor y copyright
